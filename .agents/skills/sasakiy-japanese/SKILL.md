# 日本語の校正方針

動詞と目的語、形容詞と名詞などの組合せが自然か確かめる。「影響を与える」「方針を決める」のように、表そうとする関係に合う語を選ぶ。抽象的な名詞や直訳的な言い回しが理解を妨げる場合は、具体的な動作や関係を示す表現にする。

増減や程度を述べる場合は、何の量や割合を指すかを明確にする。「結果が高く一致する」なら「結果の一致率が高い」などと整える。「逆方向の傾向」のように関係を省略した表現も、前後から明らかでなければ「人数が増えるほど待ち時間が短くなる」など、二つの対象と変化を具体的に示す。

専門語は文脈に合う意味で使う。平易に言い換える場合も、上位概念と下位概念、行為と結果などの区別を保つ。固有名や定義された用語を、一般的な言い方に合わせて変更しない。

翻訳では、原語の漢字表記や語順をそのまま使った結果、日本語として別の意味や不自然な表現になっていないか確かめる。職名や分類名などは、制度や定義の対応を確認したうえで、日本語で通じる呼び方を選ぶ。訳文だけでも意味の通る文として読めるかを確かめ、原文との照合で意味の欠落や付け足しも確認する。引用原文の表記と、その意味を説明する日本語は分けて扱う。

同じ意味の語、送り仮名、数字、記号などの表記は、指定や文章の慣習に合わせる。表記が異なるために意味や役割が区別されている場合は、その違いを保つ。「版」「バージョン」なども、出版物やソフトウェアといった対象と、文章内での用法に応じて選ぶ。

日本語は助詞を省きすぎず、自然な短い文で書く。「入力：〜」という断片より、「入力には〜を使う」と説明する。英語でも自然な文と平行な箇条書きを使い、具体的な内容が想像できない謳い文句を避ける。

他の文面や一般知識から推測できることを、誤解の可能性だけを理由に注意書きとして追加しない。
既知の制約や不一致を扱う場合も、対象固有の事実と根拠を説明する。「〜とは限らない」「〜と見なしてはいけない」といった一般的な警告に置き換えない。

## 読者向けの説明と制作・検証記録を分ける
読者が対象の概要や使い方を理解するために何を得られるかを確かめる。制作側が正確さを確認するために調べたことを、そのまま読者へ説明する必要はない。チェックサム、commit ID、取得ファイルの行番号、照合手順、監査用コードなどは、別の制作・検証記録に残す。読後の理解や利用に役立つものだけを選ぶ。

「区別する」「混同しない」「推測しない」という作業上の注意で説明を終えず、何がどう異なり、利用や結果の解釈へどう影響するのかを自然な文で伝える。入手できなかった情報や実行しなかった検証の報告は、利用判断を左右する場合に限り、必要な場所へ簡潔にまとめる。重要な評価条件、非公開の正解、注釈の曖昧さ、利用条件は残し、条件を確かめた過程と切り分ける。

# 日本語の校正例

言い換えは、示した文脈に応じた例である。同じ語が含まれる文章を一律に置換する規則として使わない。

| 観点 | 修正前 | 修正後 | 判断の要点 |
|---|---|---|---|
| 主述の対応 | この資料には十件の事例を含む。 | この資料には十件の事例が含まれる。 | 「には」に続く述語の形を整える。「この資料は十件の事例を含む」とも書ける。 |
| 条件を示す助詞 | この設定は、二つの資料を比較する。 | この設定では、二つの資料を比較する。 | 設定を動作の主体ではなく、比較を行う条件として示す場合。 |
| 助詞の省略 | 三方法を比較する。 | 三つの方法を比較する。 | 数と対象の関係を自然に表す。 |
| 修飾関係 | 調査の対象の企業の担当者に尋ねた。 | 調査対象となる企業の担当者に尋ねた。 | 「の」の連続を解き、担当者が属する企業を明確にする。 |
| 指示語 | 調査結果と改善案を送った。これについて意見を求めた。 | 調査結果と改善案を送った。改善案について意見を求めた。 | 意見を求めた対象が改善案である場合、指示先を明示する。 |
| 並列 | 資料の確認と修正する作業を担当する。 | 資料を確認し、修正する作業を担当する。 | 並べる動作の文法上の形をそろえる。 |
| 語の組合せ | 新しい方針が業務に変化を与えた。 | 新しい方針が業務に変化をもたらした。 | 表そうとする関係に合う動詞を選ぶ。 |
| 時制 | 昨日、資料を配布した。その後、担当者が内容を確認する。 | 昨日、資料を配布した。その後、担当者が内容を確認した。 | 確認も昨日完了した出来事として述べる場合。 |
| 省略した述語 | 内訳は学習用九件、確認用三件。 | 内訳は学習用が九件、確認用が三件である。 | 通常の説明文として、数量と区分の関係を補う場合。 |
| 条件の保持 | 申請が承認された場合に利用できる。 | 申請が承認されると、利用できる。 | 承認という条件を保ったまま表現を整える。 |

見出しの「調査結果」や、会話の「確認した？」などは、用途に合っていれば文に直す必要はない。「実施した調査」と「現在も続けている調査」の時制も、同じ形にそろえない。
