# 性能・電池消費のコード監査

アプリの撮影、再生、編集、位置情報、通知、DB、動画処理、保存とライフサイクルを確認。以下はコード上の確認であり、実機の電力・FPS・所要時間を測定した結果ではない。ソフトウェアエミュレーターの速度から実機の改善率を推定しない。

| 領域 | 判断・対応 |
| --- | --- |
| 撮影のバックグラウンド移行 | MainActivityの直接Camera2はActivityライフサイクルで自動停止しない。背景移行で解放する。撮影・保存途中は完了／中止通知を処理してから解放し、元の保存経路を維持する。 |
| 詳細画面のプレビュー | MainActivity内の詳細ダイアログには背景移行時のプレーヤー解放がなかった。停止・復帰処理を追加。専用編集／トリミング／レンダリング画面のプレーヤーは既にonStopで解放している。 |
| 撮影日判定 | 向きの判定で全履歴のClip・GPS・トリム等を毎回読み込んでいた。captured_at索引と、日付周辺の候補だけを取得する検索を追加。候補の最終判定は既存の撮影タイムゾーン・日付境界規則を使う。 |
| 一覧のDBアクセス | 一回の一覧作成で全件取得を繰り返していた。全件取得一回の結果を日付・向き・選択・並べ替えに再利用。 |
| サムネイル | バックグラウンド生成、400pxへの縮小、24枚のLRU、世代違いの処理破棄が既にある。複雑なディスクキャッシュや別画像ライブラリは追加しない。 |
| 準備中と録画UI | 既存の未リリース修正で、GONEによる再レイアウトと同じテキストの40msごとの更新を削減。今回も保持。シャッターの進捗描画は必要なので維持。 |
| ズーム | 既存の更新間引きと短い補間を維持。新たなレンズ推定・フレーム解析処理は追加しない。 |
| 位置情報 | 高精度GPS／ネットワークの頻度と鮮度・精度規則は維持。採用しなかった測位結果や停止後の遅延通知でUI更新を呼ばないようにした。カメラ／編集画面を離れた際の解除も確認。 |
| 地名検索 | 端末Geocoderを非同期で利用し、64件キャッシュ・同時要求の集約・8秒待機上限がある。常時ネットワーク照会や外部Places SDKを追加しない。 |
| 字幕・文字色 | プレビューは表示中の小さなフレームを一度だけ取得し、書き出しはクリップごとの固定サンプルを使う。追加デコーダーや毎フレームの画像解析は導入しない。マスク生成の共有化は解放管理を複雑にするため見送る。 |
| レンダリング | 元クリップのDB取得が二重だったため一回に統合。HEVCはハードウェアエンコーダーが利用可能な端末に限って選択し、非対応端末はH.264へ。既存の失敗時フォールバック、最大1080p設定、品質指定は維持。 |
| レンダリング画面の監視 | 状態に変化がないのに500msごとに画面全体を更新していた処理を削除。状態変化の検知周期は維持し、完了後の表示を遅らせない。 |
| 処理中の通知 | 同じ進捗率／保存状態の通知を1.5秒ごとに再送していた。変わった場合だけnotifyを呼ぶ。処理の監視は続ける。 |
| 撮影リマインダー | 要望どおり毎時の単発アラームを使用。周期的な常駐スレッドやWakeLockはない。通知の時刻・動作は変更しない。 |
| トリミング | スライダー操作の間引き、シーク再利用、背景時のループ解除を確認。ループ終端を確認する33msの周期は短いクリップの範囲を守るため維持。 |
| ファイル保存・GPS付与 | 専用IOスレッドで処理。GPS付与は再エンコードせず、完成動画の端末保存も再レンダリングせずコピーする。置き換え前に新ファイルを完成させる安全性は維持。 |
| スレッド・キャッシュ | IOプールは固定数、終了時shutdown。場所キャッシュ・サムネイル・診断記録には上限がある。より複雑な共有Executorや無期限のメモ化は導入しない。 |
| 大量データ時の一覧 | 全日付タブ・当日カードを一度に作る構造は残る。RecyclerViewへの全面移行はUI・スクロール・選択動作への影響が大きいため今回は見送る。履歴が大量の場合は実測して次に判断する。 |

## 検証と限界

ローカルでPythonテスト、JVMテスト、debug／release lint、アプリAPK・端末テストAPKのビルドを実施。JVMテスト19件・Pythonテスト4件、debug／release lint、両APKビルドはいずれも成功。lintには既存の警告が残るが、エラーはない。今回の変更の電池消費改善率、実機の背景移行中録画・復帰操作、端末テストの実行は未検証。

背景移行の検証では、通常プレビュー・録画前待機・録画中・保存中・詳細ダイアログをそれぞれ背景に移し、カメラ／GPS／デコーダーが不要に残らないことと、保存クリップ・復帰後の撮影を確認する必要がある。
